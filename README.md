# GEEK HELL ⚡️

> Premium Superhero-Inspired Apparel Platform & Interactive 3D WebGL Customizer.

Geek Hell is an Awwwards-worthy, luxury e-commerce experience allowing users to explore high-end apparel, customize 3D garments in real time, and purchase tailored apparel lines inspired by Marvel and DC universes.

---

## 🚀 Tech Stack

- **Frontend**: React 19, Vite, Tailwind CSS, TypeScript, React Three Fiber (R3F), Three.js, GSAP, Lenis, Zustand, React Query
- **Backend**: Node.js, Express.js, MongoDB Atlas, Mongoose, JWT Authentication, Cloudinary, Stripe, Nodemailer
- **Infrastructure**: Vercel (Frontend), Render (Backend), MongoDB Atlas (Database)
